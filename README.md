# ViralShop AI — MVP عملیاتی

نسخه توسعه‌ای فارسی و راست‌چین برای مدیریت آنلاین‌شاپ، محصولات، تولید محتوای AI و پیگیری عملکرد.

## امکانات موجود
- ثبت‌نام و ورود با رمزنگاری scrypt و نشست امضاشده در کوکی HttpOnly
- ذخیره‌سازی اطلاعات کاربران، فروشگاه‌ها، محصولات، اعضا، محتوا، آمار، مصرف و درخواست‌های پلن
- مدیریت چند فروشگاه با محدودیت تعداد بر اساس پلن
- آپلود تصویر محصول (JPG/PNG/WEBP/GIF تا ۵ مگابایت)
- نقش عضو مشاهده‌گر/ویرایشگر و کنترل دسترسی سمت API
- تحلیل محصول، ایده و سناریو و کپشن با API سازگار OpenAI
- حالت محلی جایگزین برای تست بدون کلید API (خروجی نمونه است، مدل هوش مصنوعی واقعی نیست)
- دستیار اختصاصی متکی بر اطلاعات فروشگاه انتخاب‌شده
- ثبت محتوا و آمار بازدید/لایک/کامنت
- سهمیه ماهانه AI بر اساس پلن
- صفحه ادمین محدود به ایمیل ADMIN_EMAIL
- ثبت رویدادهای پایه در audit log

## نیازمندی‌ها
Node.js 20.9 یا بالاتر (پیشنهاد: Node.js 22 LTS) و npm.

## راه‌اندازی ویندوز
1. فایل ZIP را Extract کنید.
2. پوشه `viralshop-ai` را در VS Code باز کنید.
3. ترمینال VS Code را باز کنید و اجرا کنید:

```powershell
Copy-Item .env.example .env.local
npm install
npm run dev
```

4. آدرس `http://localhost:3000` را باز کنید و حساب بسازید.
5. برای AI واقعی، فایل `.env.local` را باز کنید و `AI_API_KEY`، `AI_BASE_URL` و `AI_TEXT_MODEL` را از ارائه‌دهنده API خود وارد کنید. سپس سرور را با Ctrl+C متوقف و دوباره `npm run dev` کنید.

برای ادمین، قبل از ثبت‌نام `ADMIN_EMAIL` را در `.env.local` به ایمیل خود تغییر دهید و با همان ایمیل حساب بسازید.

## محدودیت‌های مهم قبل از انتشار عمومی
این نسخه یک MVP توسعه‌ای است و هنوز برای سرویس عمومی/چندسروری آماده نیست:
- دیتابیس فعلی فایل JSON محلی است؛ برای محیط واقعی باید PostgreSQL و تراکنش/مهاجرت دیتابیس جایگزین شود. روی هاست serverless یا چند نمونه اجرا نکنید.
- آپلودها در `public/uploads` ذخیره می‌شوند؛ برای تولید باید فضای ذخیره‌سازی خصوصی S3-compatible و اسکن فایل اضافه شود.
- پرداخت فقط درخواست تغییر پلن را ثبت می‌کند و هیچ تراکنش بانکی واقعی انجام نمی‌دهد. اتصال درگاه نیازمند حساب پذیرنده و کلیدهای رسمی شماست.
- بخش تیم MVP است؛ دعوت‌نامه ایمیلی، پذیرش دعوت و مدیریت مالکیت/حذف عضو هنوز کامل نیست.
- آمار محتوا دستی وارد می‌شود؛ اتصال رسمی Instagram Graph API نیازمند حساب حرفه‌ای، اپ متا و مجوزهای مربوطه است.
- rate limiting توزیع‌شده، ایمیل بازیابی رمز، تأیید ایمیل، MFA، تست نفوذ، بکاپ و مانیتورینگ تولید باید پیش از انتشار اضافه شوند.
- برای امنیت تولید، `AUTH_SECRET` را تصادفی و طولانی تنظیم کنید، HTTPS فعال باشد و فایل `.env.local` را به هیچ‌کس ارسال نکنید.

## ساختار داده
داده‌های محلی در `data/db.json` ساخته می‌شوند. این فایل محرمانه است و نباید در Git یا ZIP عمومی قرار بگیرد.

## پنل مالک و مدیر سامانه (نسخه توسعه‌یافته)

برای اینکه حساب مالک دسترسی مدیریتی و Pro دائمی داشته باشد، قبل از اجرای برنامه فایل `.env.local` را از روی `.env.example` بسازید و این دو مقدار را تنظیم کنید:

```env
ADMIN_EMAIL="alihamedgamers@gmail.com"
OWNER_EMAIL="alihamedgamers@gmail.com"
```

اگر حساب با این ایمیل از قبل ساخته شده است، لازم نیست دوباره ثبت‌نام کنید؛ یک بار از حساب خارج شوید و دوباره وارد شوید تا نقش مدیر و Pro روی حساب اعمال شود. اگر هنوز حساب ندارید، با همین ایمیل ثبت‌نام کنید.

### امکانات پنل مدیریت
- آمار تعداد کاربران، کاربران فعال، فروشگاه‌ها، محصولات، محتوا و مصرف هوش مصنوعی
- مشاهده کاربران و تغییر پلن، نقش و وضعیت فعال/مسدود
- حذف کاربر و داده‌های وابسته به او
- اعطای دستی نقش مدیر و اشتراک Pro دائمی به یک ایمیل ثبت‌نام‌شده
- مشاهده فروشگاه‌ها و حذف فروشگاه و داده‌های وابسته
- بررسی درخواست‌های پرداخت و تأیید یا رد دستی آن‌ها؛ تأیید، پلن کاربر را فعال می‌کند
- ویرایش قیمت، تعداد درخواست ماهانه و تعداد فروشگاه هر پلن
- مشاهده وضعیت تنظیمات AI بدون افشای کلید محرمانه
- مشاهده گزارش فعالیت مدیریتی

### نکات مهم استقرار
- `ADMIN_EMAIL` را فقط روی ایمیل مورد اعتماد خودتان تنظیم کنید. هر حسابی که با این ایمیل ثبت‌نام کند، مدیر اصلی می‌شود.
- `OWNER_EMAIL` حسابی را مشخص می‌کند که Pro دائمی رایگان می‌گیرد. آن را عمومی یا در اختیار دیگران قرار ندهید.
- تنظیمات AI از طریق `AI_API_KEY`، `AI_BASE_URL` و `AI_TEXT_MODEL` در `.env.local` انجام می‌شود؛ برای اعمال تغییرات سرور را مجدداً اجرا کنید.
- کلید API در پنل نمایش داده نمی‌شود.
- پرداخت آنلاین خودکار هنوز متصل نیست. پنل فعلاً درخواست‌ها را دستی بررسی می‌کند و برای دریافت وجه باید درگاه و حساب پذیرندگی واقعی به پروژه متصل شود.
- دیتابیس این نسخه فایل JSON محلی (`data/db.json`) است؛ برای استفاده عمومی/تولیدی با کاربران هم‌زمان، باید به دیتابیس پایدار مثل PostgreSQL مهاجرت شود و فایل‌های آپلودی نیز روی فضای ذخیره‌سازی پایدار قرار گیرند.
